# Codice di condotta / Code of conduct

Collabora con rispetto: critica idee e codice, non le persone. Non sono ammessi molestie, discriminazione, minacce, divulgazione di dati privati o contatti indesiderati. Usa esempi sintetici e rispetta i diritti sui materiali condivisi.

Collaborate respectfully: critique ideas and code, not people. Harassment, discrimination, threats, disclosure of private information and unwanted contact are unacceptable. Use synthetic examples and respect the rights of shared material.

Maintainers may edit or remove harmful content and restrict participation proportionately. Report conduct concerns to the repository owner through an available private GitHub contact channel. If none is available, request a private channel without disclosing sensitive details publicly.
