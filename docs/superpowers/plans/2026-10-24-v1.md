# SourcePilot 1.0 Implementation Plan

> Execute inline with the executing-plans workflow; use a fresh read-only reviewer before release. Steps use checkboxes to retain progress.

**Goal:** Publish a tested, documented SourcePilot 1.0.0 on the public repository.

**Architecture:** Preserve the local SQLite evidence core. Add focused modules for archive maintenance, pinned URL transport and optional Ollama analysis. Keep APIs and CLI as adapters to these modules.

**Tech stack:** Python 3.11–3.14, SQLite FTS5, FastAPI/Pydantic, pypdf, ReportLab, standard-library XML/ZIP/HTTP, vanilla JavaScript, pytest.

**Spec:** `docs/superpowers/specs/2026-10-24-v1-design.md`

## Global constraints

Loopback server; explicit per-run write token; immutable source versions; stable passage IDs; no automatic approval; local AI opt-in; precise indexing/analysis coverage; no sensitive operational material in Git or release archives.

## Review focus

Restored workspaces must find every original without the old absolute path. API type errors must not become 500s. Public URL validation must apply to the actual connected address. Invalid model citations must never become claims. Model changes must not reuse incompatible embedding vectors.
