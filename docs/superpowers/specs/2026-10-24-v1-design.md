# SourcePilot 1.0 design

## Product contract

Deliver a local, single-user research application for importing sources, finding passages, drafting cited claims, comparing evidence, reviewing uncertainty, and exporting reports. Web UI, API and CLI share the same services. The stable 1.0 contract covers the local workflow; optional Ollama models add semantic retrieval and reviewable AI proposals. Model quality is not a guarantee of factual correctness.

## Delivery decisions

- Retain the Python/FastAPI/SQLite application and its existing workspaces. Use additive schema migrations. Support Python 3.11–3.14.
- Import UTF-8 text, Markdown, HTML, text PDFs and DOCX paragraphs/tables. Keep original bytes, SHA-256, source version and passage locators. Bound compressed document expansion and HTTP responses.
- Pin URL connections to validated public IP addresses, including redirects, while retaining TLS hostname verification. Validate API JSON with typed models; reject invalid IDs, origins, hosts and oversized requests with structured errors.
- Resolve retained objects relative to the workspace. Provide integrity diagnostics and a consistent ZIP backup with a database snapshot, originals and checksums. Restore only into a new directory after validating member paths, checksums, sizes and the database.
- Optional Ollama integration is explicitly configured at startup and restricted to a loopback endpoint and installed local models. No automatic model downloads. Record model digest, prompt version, input hash, parameters and validated results for every AI analysis.
- Cache passage embeddings by immutable passage ID and model identity. Split long passages into overlapping windows, pool normalized vectors, and report indexing coverage. Semantic search never silently falls back to lexical search.
- AI claim suggestions must contain an existing passage ID and an exact quote from the supplied context. Candidate disagreements must cite one passage from each compared source. Validate all citations before retaining a run. A person explicitly accepts a suggestion as a proposed claim and reviews it separately.
- Bound analysis context and show analyzed/total passage counts and truncation. Source instructions are untrusted input, never executable commands. AI cannot approve claims, fetch URLs or mutate evidence on its own.
- Changes to a claim or its evidence invalidate the previous review. Reports include only approved and uncertain claims by default. Preserve complete source hashes in both report formats.
- Publish license, attribution, support, security, contribution and funding information. Keep local workspaces, generated reports and private operational material outside tracked files and distribution artifacts.

## Validation

Regression tests cover old workspace migration, original integrity and portability, backup/restore, hostile archives, malformed API payloads, URL target pinning, offline models, embedding cache/model changes, invalid AI citations, explicit proposal acceptance, and report provenance. Run the full Python suite, browser interactions, packaging checks, dependency audit and Windows/Linux CI. Record which model tests used a real installed runtime and which used a controlled HTTP server.

## Deferred beyond 1.0

OCR, hosted/multi-user service, autonomous web discovery, trust scoring, automatic truth decisions, and a universal PDF font bundle. Unsupported PDF glyphs produce an explicit error and Markdown remains available.
