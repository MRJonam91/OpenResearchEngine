# Presentazione e feedback / Sharing and feedback

## Italiano

SourcePilot è una web app locale per passare da documenti a un report con citazioni ispezionabili. Conserva originali e versioni, collega affermazioni a passaggi e richiede una revisione umana. La 1.0 include ricerca testuale, report Markdown/PDF e backup; Ollama è opzionale. La [prima prova](FIRST-RUN.md) usa una fonte inventata e non richiede modelli AI.

Cerco feedback sul percorso **importa → trova il passaggio → revisiona → esporta**: in quale punto perdi il filo della fonte? Per riprodurre un problema usa il file fittizio e il canale [Support](../SUPPORT.md). Non condividere documenti di lavoro o workspace. Nessuna promessa di verifica automatica dei fatti, OCR o hosting multiutente.

## English

SourcePilot is a local web app for turning documents into reports with inspectable citations. It retains originals and versions, links claims to passages and keeps review decisions human. Version 1.0 includes text search, Markdown/PDF reports and backups; Ollama is optional. The [first-run walkthrough](FIRST-RUN.md) uses a fictional source and needs no AI model.

Feedback wanted on **import → locate a passage → review → export**: where do you lose track of the evidence? Use the fictional file and [Support](../SUPPORT.md) to reproduce problems. Keep work documents and workspaces private. Automatic fact verification, OCR and multiuser hosting are not included.
